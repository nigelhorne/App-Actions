   53: =head1 DESCRIPTION
   54: 
   55: In Perl, a routine whose name starts with C<_> is private by convention
   56: only: any code can still call it.  L<Sub::Private> makes the rule real.  In
   57: C<enforce> mode, a call to a private routine from outside its own package
   58: dies.
   59: 
   60: There is a catch.  L<Sub::Private>'s mode is one setting for the whole
   61: program.  If one module set it to C<enforce> for good, every module loaded
   62: after it would be switched too, even modules that did not ask for it.
   63: 
   64: So this distribution never changes the setting for good.  Each module, at
   65: the end of its file, sets the mode with C<local> for just one call to
   66: L<Sub::Private>, and gives that call the list of its private routines.  This
   67: module makes that list.  Because the list is made from the code, a private
   68: routine added later is protected automatically; nobody has to remember to
   69: add it to a list.
   70: 
   71: =head1 METHODS

  158: =head1 LIMITATIONS
  159: 
  160: =over 4
  161: 
  162: =item * The listing has to run after the routines are compiled, which is
  163: why the C<BEGIN> block goes at the end of the file.  A routine compiled
  164: after it (by a string C<eval>, say) is not protected.
  165: 
  166: =item * Privacy is checked on every call, by walking C<caller>, so a private
  167: routine costs more to call than a public one.  None of this distribution's
  168: private routines is called in a tight loop.
  169: 
  170: =item * The check is bypassed under a test harness (C<HARNESS_ACTIVE>), which
  171: is how the white-box tests reach the private routines.  Run a test file
  172: without the harness to see the checks in force.
  173: 
  174: =item * A private routine handed to another package as a code reference is
  175: checked when that package calls it, and fails.  Hand over a closure that
  176: calls it instead.
  177: 
  178: =back
  179: 
  180: =head1 COMMON PITFALLS
  181: 
  182: =over 4
  183: 
  184: =item * B<Call it at the end of the file.>  It sees only the routines that
  185: are already compiled.  Put the C<BEGIN> block after the last C<sub>.
  186: 
  187: =item * B<Always use C<local> for the mode.>  Write C<local
  188: $Sub::Private::config{mode} = 'enforce';> inside the C<BEGIN> block.
  189: Without C<local>, every module loaded later is enforced too.
  190: 
  191: =item * B<Leave out protected routines.>  A routine that a subclass may
  192: call must be passed in C<@except> (and given to L<Sub::Protected>), or the
  193: subclass's calls will die.
  194: 
  195: =item * B<Names starting with two underscores are not listed.>  C<__foo>
  196: does not match; only C<_> followed by a letter or digit does.
  197: 
  198: =item * B<Imported routines are not listed.>  A routine imported from
  199: another module belongs to that module.
  200: 
  201: =item * B<Once Sub::Private has wrapped them, they are not listed either.>
  202: The wrapper belongs to L<Sub::Private>, so asking about a module that has
  203: already run its C<BEGIN> block (for example C<App::Actions::Util>, once it
  204: is loaded) returns an empty list.  Ask before the C<import>, as the
  205: C<BEGIN> block does.
  206: 
  207: =item * B<Tests run with the checks off.>  Under C<prove>,
  208: C<HARNESS_ACTIVE> is set and the checks are bypassed.  Run
  209: C<perl -Ilib t/file.t> (without C<prove>) to test with them on.
  210: 
  211: =back
