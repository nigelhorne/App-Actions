   95: 
   96: When something goes wrong, this distribution throws (C<die>s with) an
   97: C<App::Actions::Error> object.  The object has:
   98: 
   99: =over 4
  100: 
  101: =item * a B<code>, such as C<workflow.file_missing>.  The code never

  107: 
  108: =item * the B<arguments> used to build the message, such as C<{ file =E<gt>

  111: =item * a B<location>, such as C< at lib/App/Actions.pm line 42.>, the same
  112: text C<croak> adds.
  113: 
  114: =back
  115: 
  116: As a string, the object is exactly the message followed by the location: the

  118: a string, prints it or matches it with a regular expression sees no

  122: distribution calls C<< $self->throw($code, \%args) >> from
  123: L<App::Actions::I18N>, which looks the code up in the message catalogue,
  124: translates and fills in the message, and throws the object.  The codes are
  125: the keys of the catalogue in L<App::Actions::I18N::en>.

  522: =head1 LIMITATIONS
  523: 
  524: =over 4
  525: 
  526: =item * Only messages raised through the catalogue are objects.  Errors from
  527: Perl itself, from CPAN modules and from code that still calls C<croak> with a
  528: literal are strings; L</describe> and L</caught> accept both so a caller does
  529: not have to know which it was given.
  530: 
  531: =item * The code is the catalogue key, so renaming a key is an interface
  532: change.  The keys are listed in the language modules under
  533: L<App::Actions::I18N>.
  534: 
  535: =item * The arguments are copied when the exception is made, but values in
  536: them that are references are shared with the code that threw it.

  540: =head1 COMMON PITFALLS
  541: 
  542: =over 4
  543: 
  544: =item * B<Do not match the message text.>  It is translated, and its
  545: wording may change.  Use L</is> with the code.
  546: 
  547: =item * B<Not every exception is an object.>  Errors from Perl and from
  548: other modules are strings.  Use L</caught>, which returns C<undef> for them,
  549: before you call a method on C<$@>.
  550: 
  551: =item * B<C<is> needs a trailing dot for a family.>  C<is('runner.image')>
  552: matches only that exact code; C<is('runner.image.')> matches every code
  553: that starts with C<runner.image.>.
  554: 
  555: =item * B<C<args> returns a copy of the hash, but not of what is inside
  556: it.>  If an argument is a reference, changing what it points to changes the
  557: error too.
  558: 
  559: =item * B<A method call does not work inside a string.>  C<"$error-E<gt>code">
  560: prints the whole error followed by C<-E<gt>code>.  Write C<'...' .
  561: $error-E<gt>code>.
  562: 
  563: =item * B<The object is always true.>  Even an error with an empty message
  564: counts as true, so C<if ($@)> works as expected.
  565: 
  566: =item * B<Keep a copy of C<$@>.>  Any C<eval> you run later (even inside a
  567: destructor) can reset it.  Write C<my $error = $@;> first.
  568: 
  569: =back
