Changes

The highlights of each release. The full revision history, including test and documentation changes, is in the Changes file that ships with the distribution.

0.002.1 — 25 October 2026

  • action-run cache no longer reports an image as missing when Docker has it but gives no size for it, and --prune removes such an image instead of forgetting it.
  • A run that uses a kept image without pulling it again updates the image's last use, so cache --prune --older-than no longer removes an image that runs still use.
  • if: false and fail-fast: false work on Perl 5.36 again, where a core boolean copied through Storable became an empty string and ran the job.
  • YAML::PP 0.38 is required: older versions do not load true and false as Perl's own booleans.
  • A pull that fails while a job runs is reported in the chosen language, as the preflight's already was.
  • The tests pass from a checkout with CRLF line endings, and the suite copies itself to a path containing spaces and runs there again.
  • New t/integration.t: end-to-end tests across the modules, with unwritable and unsearchable directories, an unreachable daemon, slow and failing pulls, and malformed answers and files.
  • The core modules the tool and its tests use are all declared as prerequisites.

0.002.0 — 23 October 2026

  • Security: an environment value is interpolated only once, so ${{ }} text from a context value — a commit message, say — is not evaluated again. A variable that refers to itself is an error.
  • Security: a docker:// image is likewise interpolated once, and log names and run ids that are not plain file names are refused.
  • Warnings and errors go through a Log::Abstraction logger, so they can be collected, filed or discarded. Progress and the summary stay on standard output.
  • The configuration that Object::Configure adds — App__Actions sections and App__Actions__* variables — is documented.
  • The cache and logs listings, and a child process's error lines, are translated.
  • Windows: a missing program is status 255 and is no longer retried through cmd.exe, which would have read & and | in the arguments.
  • Bug fixes across Expression, Workflow, Runner, Steps, Containers, Images, Parallel, Process, Cache, Check, Schema, Action and the preflight's deferred images.
  • New white-box, black-box-against-the-POD, and Changes tests.
